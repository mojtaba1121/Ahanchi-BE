# AhanChi Backend

بک‌اند سامانه جمع‌آوری ضایعات فلزی آهن‌چی با NestJS، MongoDB و Redis.

## امکانات نسخه اول

- ورود با شماره موبایل و JWT
- نقش‌های مدیر کل، مدیر و نماینده
- مدیریت نماینده‌ها و دسته‌بندی مواد
- ثبت idempotent فروشنده، خرید و تراکنش مالی برای همگام‌سازی آفلاین
- محاسبه مبلغ خرید در سرور بر اساس وزن گرم و قیمت هر کیلو به تومان
- دفتر حساب فروشنده و مانده بدهکار/بستانکار
- گزارش کلی، تفکیک مواد، روند روزانه، بزرگ‌ترین طلبکار و مقایسه نماینده‌ها
- Swagger در مسیر `/docs`
- Health Check در مسیر `/api/v1/health`
- Seed خودکار و قابل‌تکرار

## Seed پیش‌فرض

هنگام اولین اجرا موارد زیر ایجاد می‌شوند:

- نقش‌ها: `SUPER_ADMIN`، `MANAGER` و `REPRESENTATIVE`
- مواد: آهن، مس، آلومینیوم، برنج، چدن، استیل، سرب، روی و ضایعات مخلوط
- مدیر اولیه بر اساس `SEED_ADMIN_*`

مدیر اولیه با `mustChangePassword=true` ایجاد می‌شود. رمز واقعی را هرگز در Git ثبت نکنید.

## اجرای محلی

```bash
cp .env.example .env
npm ci
npm run start:dev
```

MongoDB و Redis باید بر اساس آدرس‌های `.env` در دسترس باشند. مستندات API:

```text
http://localhost:3000/docs
```

## اجرا با Docker روی Ubuntu

```bash
cp .env.example .env
```

پیش از اجرا حتماً مقادیر `JWT_SECRET` و `SEED_ADMIN_PASSWORD` را در `.env` تغییر دهید. برای ساخت JWT secret:

```bash
openssl rand -hex 32
```

سپس:

```bash
docker compose up -d --build
docker compose ps
curl http://127.0.0.1:3000/api/v1/health
```

MongoDB و Redis به پورت عمومی سرور متصل نشده‌اند و فقط داخل شبکه Docker قابل دسترسی هستند.

## پشتیبان‌گیری

```bash
chmod +x scripts/backup.sh
./scripts/backup.sh
```

فایل پشتیبان در `./backups` ایجاد می‌شود. این پوشه را به فضای ذخیره‌سازی جداگانه منتقل کنید.

## قرارداد حساب فروشنده

- خرید: مانده طلب فروشنده را افزایش می‌دهد.
- پرداخت به فروشنده: مانده طلب فروشنده را کاهش می‌دهد.
- دریافت از فروشنده: مانده طلب فروشنده را کاهش می‌دهد و در صورت منفی‌شدن، فروشنده بدهکار است.

وزن همیشه به‌صورت عدد صحیح بر حسب گرم و مبالغ به‌صورت عدد صحیح بر حسب تومان ذخیره می‌شوند.
